# Mídia do portfólio

Coloque os arquivos reais do portfólio nestas pastas:

- `profile/saad.jpg`: foto de perfil.
- `videos/`: vídeos finais e capas dos projetos audiovisuais.
- `design/`: artes, campanhas e peças gráficas.
- `identities/`: logotipos e aplicações de identidades visuais.

Como o portfólio atual é uma página HTML estática na raiz do repositório, use caminhos relativos a partir da raiz, por exemplo:

- `media/profile/saad.jpg`
- `media/videos/projeto-01.mp4`
- `media/design/campanha-01.webp`
- `media/identities/marca-01.svg`

Antes de publicar, confira se os caminhos configurados em `index.html` correspondem aos arquivos adicionados. Use imagens otimizadas para web e evite enviar arquivos de vídeo muito pesados.
